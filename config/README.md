# Configuración

En esta carpeta debéis crear la configuración y el diccionario de datos que correspondan a vuestro diseño, siguiendo las guías del profesor.

Documentad los valores elegidos, sus unidades, dominios, dependencias y justificación. Los nombres y formatos deben ser coherentes con el resto del proyecto.

La plantilla no contiene parámetros, catálogos ni configuraciones rellenadas. El equipo decide cómo organizar estos archivos y registra su utilización en `docs/reproducibilidad.md`.
