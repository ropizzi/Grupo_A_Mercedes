# Datos

Los datos deben ser generados por el equipo conforme a las guías docentes. No se dispone de datos reales de Mercedes-Benz para esta práctica.

- `muestras/`: archivos pequeños que se versionan para revisar y comprobar el desarrollo.
- `generados/`: datasets grandes producidos localmente y entregados por el canal indicado por el profesor.

Los archivos generados deben poder reproducirse a partir del código y la configuración del equipo. Registrad su procedencia, versión y validación.

La plantilla no contiene registros, cabeceras CSV ni datasets.
