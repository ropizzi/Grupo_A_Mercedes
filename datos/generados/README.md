# Datasets grandes

Esta carpeta está destinada a los archivos producidos durante la generación local. Su contenido, salvo este README, está excluido del historial Git mediante `.gitignore`.

El equipo debe generar, validar y entregar los datasets exigidos. Utilizad el canal de entrega comunicado por el profesor y dejad constancia de su ubicación y reproducción en la documentación.

No forcéis la incorporación de estos archivos al historial para sortear `.gitignore`. Consultad cualquier cambio de procedimiento con el profesor.
