# Entregas y evidencias

El profesor indicará fechas, canal y forma de entrega en Classroom 50 o en el espacio de la asignatura. Esta plantilla no configura ni realiza entregas automáticamente.

Para cada hito, preparad una descripción con:

- Hito y fecha.
- Trabajo completado y aspectos pendientes.
- Enlaces a los archivos y a las pruebas o resultados relevantes.
- Referencia del commit entregado, conforme al procedimiento indicado por el profesor.
- Ubicación de los datasets grandes y demás archivos entregados fuera del historial Git.
- Forma de reproducir las evidencias.

Podéis utilizar el formulario **Entrega intermedia** de Issues para preparar la revisión. Abrir ese Issue no sustituye el envío mediante Classroom 50 cuando el profesor lo requiera.

El profesor registrará la versión evaluada. No borréis ni reescribáis el historial ya presentado durante el seguimiento.
