# Notebook del proyecto

El equipo debe crear aquí el notebook Jupyter con el nombre y los apartados establecidos en el enunciado.

Incluid explicaciones propias, resultados obtenidos y conclusiones justificadas. Antes de entregar, comprobad que se ejecuta de principio a fin desde un kernel reiniciado.

Coordinad la edición para evitar cambios simultáneos incompatibles. Los módulos de código deben estar en `src/` cuando corresponda.

La plantilla no incluye un notebook con celdas preparadas ni contenido desarrollado.
