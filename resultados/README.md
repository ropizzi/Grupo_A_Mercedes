# Resultados

Guardad aquí los resultados obtenidos por el equipo, identificando el experimento o validación, la configuración y la versión de código utilizados.

- `figuras/`: gráficos seleccionados y explicados.
- `tablas/`: resúmenes de mediciones y calidad.

Las figuras y tablas deben corresponder a ejecuciones reales. Evitad archivos redundantes o resultados sin trazabilidad.

La plantilla no incluye mediciones, gráficos ni conclusiones.
