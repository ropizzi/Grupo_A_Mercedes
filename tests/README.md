# Pruebas

El equipo debe diseñar y escribir las pruebas necesarias para demostrar el cumplimiento de los requisitos del proyecto.

Documentad qué comprueba cada prueba, cómo se obtuvo el resultado esperado y cómo puede ejecutarse. Los casos pequeños válidos y los errores intencionados deben mantenerse diferenciados según las guías.

Esta carpeta no contiene pruebas implementadas, fixtures ni respuestas esperadas. No se ha configurado corrección automática.
